# Project Visual Assets

## Social Preview

`cineops-social-preview.png` is the canonical 1280 x 640 repository social card. It communicates the CineOps flow from film planning through continuity checks to a release gate.

The raster artwork was generated for this project with OpenAI image generation and reviewed by the maintainer. It contains no third-party logos, project metrics, participant claims, or production media.

When updating the card, preserve these constraints:

- exact title `CineOps`;
- exact subtitle `Production Control for AI Filmmaking`;
- 2:1 composition with safe margins;
- no adoption numbers, stars, download counts, partner logos, or model endorsements;
- no private or copyrighted production assets.
