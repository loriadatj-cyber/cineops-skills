# Security Policy

## Supported Versions

Security fixes currently target the latest release.

## Reporting

Do not open a public issue for a vulnerability involving code execution, credential exposure, path traversal, or untrusted production assets. Use GitHub's private vulnerability reporting for this repository.

CineOps does not require network access or credentials. Treat third-party scripts, media, prompts, and project files as untrusted. Review optional adapters before granting account or publishing permissions.
