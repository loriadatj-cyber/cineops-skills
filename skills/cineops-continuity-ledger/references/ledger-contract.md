# Ledger Contract

## Stable Identity

Use `CHAR-*`, `LOC-*`, and `PROP-*` IDs. A display name may change; an ID may not. Alias names belong inside the entity record.

## Evidence

Canonical facts should include a source reference when practical. Keep fact, interpretation, and proposal separate.

## Scene State

Each scene state names involved IDs and records entry and exit. A state transition should explain what changed and which observable beat caused it.

## Conflict Policy

Never resolve contradictory approved sources by file timestamp alone. Mark the field as conflicted, list sources, identify affected scenes, and request an owner decision.
