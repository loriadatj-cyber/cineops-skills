# Diagnostic Rubric

Score each dimension from 0 to 3. Scores support discussion; evidence determines the verdict.

| Dimension | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| Causality | disconnected beats | weak links | mostly causal | every turn creates the next |
| Intention | absent | stated only | playable | visible and pressure-tested |
| Value change | none | cosmetic | meaningful | irreversible or costly |
| Visual action | abstract | dialogue-heavy | mostly visible | action carries meaning |
| Rhythm | inert | uneven | functional | escalating with purposeful contrast |
| Producibility | undefined | high ambiguity | manageable | stable and generation-readable |

Never average away a blocker. A single causality or identity blocker can stop handoff even when the total score is high.
