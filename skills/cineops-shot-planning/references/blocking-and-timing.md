# Blocking And Timing

## Spatial Minimum

For each speaking or acting subject, know the starting position, facing direction, target, path, and final position. Establish screen direction before crossing the axis. If geography is intentionally hidden, state what the audience should and should not know.

## Timing Budget

Estimate duration from physical beats rather than dialogue length alone. Include recognition, reaction, travel, object handling, and settling time. If the required beats do not fit, split the shot or remove a beat.

## State Boundary

Entry state is what must already be true on the first usable frame. Exit state is what must be true on the final usable frame. These states are contracts for adjacent shots, not prose summaries.
